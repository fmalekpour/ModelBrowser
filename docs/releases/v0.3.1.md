# ModelBrowser v0.3.1

Fixes a packaging regression in the v0.3.0 installer and unpacked distribution that caused Open folder to do nothing and prevented the Settings button from appearing.

Three.js stores its loaders and controls under `examples/jsm`. The packaging tool excluded this directory by default, preventing the interface module from loading. These runtime addons are now included explicitly.

Both browser entry points and their complete import chains, including transitive addons, are verified inside the built app archive before an installer can be generated. The regression tests also check import-map content-policy hashes.

Download `ModelBrowser-Setup-0.3.1-x64.exe` and install it over v0.3.0. The app identity and user-data location are unchanged. Settings and cached thumbnails are retained. The installer is unsigned.

Source download: `ModelBrowser-0.3.1-source.zip`. Checksums: `SHA256SUMS.txt`.
