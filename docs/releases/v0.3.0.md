# ModelBrowser v0.3.0

First open-source Windows release of ModelBrowser, an offline STL/3MF library browser.

## Highlights

- Folder and subfolder browsing, search, sorting, and paginated thumbnails.
- Interactive 3D preview with rotation, zoom, pan, camera presets, and wireframe.
- Background thumbnail generation for large libraries.
- 29 persistent settings, including thumbnail size/resolution, page size, cache policy, preview appearance, and performance limits.
- MIT-licensed source, tests, and developer documentation.

## Downloads

- **Windows x64 installer:** `ModelBrowser-Setup-0.3.0-x64.exe`
- **Source:** `ModelBrowser-0.3.0-source.zip` or GitHub's automatic source archives
- **Checksums:** `SHA256SUMS.txt`

Run the installer for a first installation or to replace an older installed version with the same app identity. Settings and thumbnails are retained. Updates are installed manually; there is no in-app automatic updater.

## Known limitations

- Some slicer-specific 3MF extensions/materials are not supported by the loader.
- Especially complex selected models can pause the preview while loading.
- Windows x64 is the packaged target; other platforms are not yet tested.
- This setup executable is unsigned.

Automated tests cover parsing, synthetic large-library behavior, settings, caching, and worker lifecycle. Before publishing this draft, record results of normal-desktop installation, launch, GPU interaction, and upgrade checks from `docs/RELEASING.md`.
