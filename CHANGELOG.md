# Changelog

## 0.3.0

- Added 29 persistent settings for library layout, thumbnails, cache policy, preview appearance, interaction, and performance.
- Displayed the application version in the window title, header, and settings page.
- Added disk-cache size and expiry policies, cache usage information, and cache clearing.
- Prepared the first open-source distribution with the MIT license, developer/release documentation, repeatable tests, a Windows installer, and draft-release automation.

## 0.2.0

- Moved thumbnail generation to a separate renderer process.
- Added paginated browsing, bounded thumbnail memory, cancellation, timeouts, and worker recycling.
- Improved scanning and added synthetic large-library tests.

## 0.1.0

- Initial STL/3MF folder browser with rendered thumbnails and an interactive preview.
- Added searching, subfolders, camera presets, wireframe, and model metadata.
